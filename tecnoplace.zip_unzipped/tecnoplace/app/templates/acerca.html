Acerca de TecnoPlace

TecnoPlace es una plataforma segura para la compra y venta de dispositivos tecnológicos con validación de identidad de usuarios y arquitectura modular, desarrollada en el marco del curso de Arquitectura de Software de UNIMINUTO.

Arquitectura

Cliente-Servidor bajo patrón MVC, con cuatro capas: presentación (HTML/CSS/JS), controladores (Flask Blueprints), servicios (lógica de negocio) y persistencia (SQLAlchemy + SQLite).

Stack tecnológico

  • Backend: Python 3.11 + Flask + Jinja2
  • Base de datos: SQLite (migrable a PostgreSQL)
  • Seguridad: bcrypt para hash de contraseñas, Flask-WTF para CSRF
  • Multimedia: Pillow para procesar imágenes
  • Frontend: HTML5, CSS3 (paleta verde), JavaScript vanilla
  • Despliegue sugerido: Gunicorn + Nginx en Ubuntu

Decisión arquitectónica clave

Ningún usuario puede publicar productos sin haber sido verificado. Esto se modela en UML con el caso de uso «Subir foto cédula y selfie» con relación «include» hacia «Validar identidad».
